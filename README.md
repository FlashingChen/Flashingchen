## My Projects

- **My favorite project**: [LaochenDNS](https://github.com/FlashingChen/LaochenDNS) — A **desktop app** that provides **aggregated management** of multi-vendor DNS. All data is stored **locally** on your machine, with no communication to other servers except for API calls.

- **An experimental app**: [LaochenAutoZIP](https://github.com/FlashingChen/LaochenAutoZIP) — Originally created for version control before I became familiar with **Git**. There are better alternatives — Git. However, if your workflow involves **compressing all files in your workspace** and uploading to a server with **version control** each time, you might consider this project.

- **The first app to recreate the Spring Festival Gala magic trick**: [Laochen Calculator](https://github.com/FlashingChen/LaochenCalc) — Powered by *GPT-5.2*, it recreates the **2026 Spring Festival Gala calculator** (I provided the idea, it wrote the code). You can also [try it online](https://app.chenyuxia.com/calc/).

- **Could serve as your personal homepage**: [Laochen's Homepage](https://github.com/FlashingChen/VibeHome) — Built with *Google AI Studio*, it features a **tech-inspired / cinematic / animation-rich** design. You can [preview it live](https://chenyuxia.com). It allows you to quickly and freely customize multiple sections **within a single file**.

- **Team project for the 2026 Xiaohongshu Hackathon**: [NoteRx (薯医)](https://github.com/jiangmuran/noterx) — I was responsible for part of the project development, promotional materials, and server security. As of 2026/4/26, the project has distributed 300M+ tokens and reached over **20K** UV.

- **A skill that helps me learn competitive programming**: [OI.skill](https://github.com/FlashingChen/oi.skill) — A Socratic-method skill that keeps track of your strengths and weaknesses across sessions and guides you to keep improving. [Read the blog post](https://blog.chenyuxia.com/archives/yong-wan-aiyan-jing-hui-liao-shou-fei-liao-yu-shi-wo-zuo-liao-ge-skill).

- **A family memory bot that never gets in the way**: [ChatterCatcher](https://github.com/FlashingChen/chattercatcher) — A local-first, evidence-driven RAG memory bot for Feishu/Lark family groups. It quietly saves important messages, files, and fragmented context, then answers when @-mentioned with traceable citations.

- **A self-hosted notification relay**: [Sender](https://github.com/FlashingChen/Sender) — The Android app continuously captures notifications from WeChat, X, and more and reports them upstream; the self-hosted Go server stores them and offers a web console plus an OAuth-authorized API and CLI for agents. Your data stays yours.

- **A local-first time tracker**: [MyTime](https://github.com/FlashingChen/MyTime) — An open-source, cross-platform app: one tap to start or stop timing, with a timeline, statistics, category management, and optional AI time suggestions.

- **A plugin for DeepSeek Harness**: [dsh-worktree](https://github.com/FlashingChen/dsh-worktree) — Brings the Codex-style permanent git worktree workflow into DSH: worktrees survive sessions and restarts, so any later session can pick up right where the previous one left off.

- **A desktop console for DeepSeek Harness**: [dsh-desktop-hub](https://github.com/FlashingChen/dsh-desktop-hub) — An Electron + TypeScript desktop management hub with multiple tabs for Harness / Plugin / MCP / Skills. Double-click and go.

- **One memory that belongs to you**: [memosaic](https://github.com/FlashingChen/memosaic) — A local-first Chrome MV3 extension that keeps one Markdown document you own, letting every supported AI chat read from it and write to it. Your memory shouldn't live in someone else's database.
